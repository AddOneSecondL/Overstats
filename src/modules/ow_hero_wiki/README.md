# 英雄图文百科与定向查询

保留原接口及 `hero?问题` 格式：

```http
POST /api/v2/ow_hero_wiki
Content-Type: application/json

{"hero":"猎空","question":"闪现最多可以储存几次？冷却多久？"}
```

同一请求发送到 `/api/v2/ow_hero_wiki/image` 可获取 PNG。问题留空为完整百科；填写问题后图片展示回答、命中的技能或威能及来源。调试页面选择「英雄百科」，填写英雄与问题，选择图片模式即可。

## 数据与检索

- 数据来自既有 Fandom Wiki 抓取与解析流程，中文名称和简介沿用本地 query_tool 配置。
- Wiki 正文和图标查询读取 `config.PATCH_NOTES_INTERNATIONAL_PROXY`；需要代理访问 Fandom 时在运行配置中填写代理地址。
- 威能不再按列表位置套用中文名：仅采用显式名称匹配，否则使用 Wiki 名称及说明（配置模型后尝试翻译）。合作模式的备注明确标注 PvE，避免其数值混入普通模式。
- 对概览、基础属性、技能参数、威能、所有机制备注及 6v6 备注分块，使用中文双字切分、英文词切分、术语扩展和 BM25 检索。明确指定技能时限定该技能，优先返回参数正文。
- 取前 5 个片段交给现有分析模型，要求以 `[1]` 格式引用。无需额外数据库、embedding API 或相邻 `overstats-wiki-rag` 目录；这是单英雄结构化资料范围的检索，并非全站 Wiki 搜索或向量检索。
- JSON 新增 `citations`（编号、标题、正文、来源 URL、内容哈希、所属条目、检索分数）及 `answer_mode`。
- `generated` 表示生成回答且引用编号通过检查；`extractive` 表示仅返回检索原文（未配置模型、调用失败或引用无效）；`insufficient_evidence` 表示没有命中资料。编号校验不等价于事实正确性验证。
- 页面使用修订校验缓存：有查询时，每 5 分钟最多请求一次 `revid` / `timestamp` 元数据；修订未变时复用正文，变化时才下载正文。正文哈希未变则复用解析和翻译。不是后台定时任务，无查询时不会请求 Wiki。
- JSON 来源中提供 `revision_id` 和 `modified_at`，图片显示 Wiki 修改时间（UTC）。旧缓存自动升级；旧的 24 小时有效期不会阻止新修订检查。校验失败保留原缓存文件并按原有接口返回获取失败，不把失败标为“已验证”。
- 答案仍使用独立有效期，检索上下文变化会使答案缓存失效。此检查针对英雄页面本身，不包含被引用模板的独立修订；图标地址单独每日更新，翻译配置变化也会独立触发补翻译。资料未覆盖的版本历史、故事章节及跨英雄问题仍需要扩充数据范围。

## 渲染

渲染入口委托给 `editorial.py`。沿用今日总结的深色基调与分组强调色，采用人物封面、独立数据栏、编号章节和轻量来源脚注。参数按列表对齐，简短数值放大，长条目的机制说明单独分栏；成对技能与威能保持固定阅读顺序、统一底边，减少套框。过暗的英雄强调色会自动提亮。

封面的斜切边与装饰线使用同一斜率，英文装饰标题替换为「英雄档案」。数据数字使用资源库 `num.ttf`（Grota Rounded ExtraBold），与中文单位按基线混排。生命构成每格代表 25 点，余量显示部分格，较高生命值自动分行；生命、护甲、护盾分别使用白、金、蓝色。威能经验使用独立的两级色块，次级以菱形、主要以双层六边形标记。

参数标签左侧使用 `stat_icons.py` 的统一纯白线性图标：24 单位画布、2 单位线宽，按字段键匹配，兼容旧缓存的中文标签。图标用透明度绘制抗锯齿，所有可见 RGB 均为纯白；无需外部下载。新增未知字段使用统一的参数调节图标。标签预留固定图标间距并动态计算行高。

机制词条各自显示为可换行的 tag，保留完整文字。`parameter_style.py` 集中配置数值参考分档：灰蓝、青蓝、绿、金四档，伤害等增益项正向，冷却、装弹、施放等成本项反向。简单范围的两端分别着色，单位和图标保留原色。默认切点是可调整的显示参考值，不代表对局强度或跨英雄评级；例如伤害切点为 25/75/150，冷却切点为 3/6/12 秒。条件公式、多种模式或单位混合、未支持单位及方向不明确的值保持白色，避免擅自抽取其中一个数字评分。

技能和威能保留 Wiki 的 `ability_image` 为 `icon_file`，通过 `imageinfo` 批量解析 `icon_url`（含文件名规范化和重定向），优先加载 Wiki 图标并缓存图片文件。地址每天刷新；查询失败或缺图在五分钟后重试，不中断百科。远程图标不可用时，本地图标从 `ow_guess_assets/shared/hero_icons/<英雄>/Abilities|Perks/<中文名称>.png` 读取，文件缺失时保留文字卡片。标题、回答、参数和备注均按实际文本动态测量，保留长 URL 换行；重复引用按标题和来源合并显示。

模型配置复用项目现有 `ANALYSIS_*` 配置；没有模型仍可完成检索，英文和中英混合的名称、说明、参数注释、标签、普通及模式备注均可翻译；数字序列与百分号数量变动、空翻译会被拒绝并保留原文。英文专名与通用缩写可保留。启用或更换模型端点/模型后，下次查询会补翻译缓存，无需等待 Wiki 修订；失败五分钟后重试。没有模型时，除基础术语和单位映射外，英文保留原文。Wiki 数据可能滞后于游戏版本，页面与本地中文配置也可能不完全同步。
